# Homelab

I repurpose old laptops to learn Linux administration, networking, and self-hosting by deploying and troubleshooting real services.

## Upgraded homelab

The latest documented build uses a **Dell Inspiron 15-3567** running **Debian Trixie** from an SSD, with a **1 TB HDD** for additional storage.

| Notes | What they cover |

| [Ledgerdesk deployment](upgraded-homelab/ledgerdesk.md) | Nginx hosting, deployment troubleshooting, and the separate PostgreSQL API test |
