# Services and access

| Service | What I did |
|---|---|
| SSH and SCP | Managed Debian from Windows and transferred files to the server. |
| DHCP reservation | Kept the server's LAN address consistent. |
| Tailscale | Connected the Windows laptop and Debian server for remote access. |
| Samba | Moved the share to a dedicated directory and tested it from an iPhone. |
| Docker and Portainer | Ran containers and managed them through Portainer. |
| Homepage | Set up a dashboard for homelab services. |
| File Browser | Set up browser-based file access. |

I use SSH on the home network for terminal access and Tailscale when away. The original [networking](../Docs/network.md), [SSH](../Docs/ssh.md), and [Samba](../Docs/samba.md) notes cover the early setup.
